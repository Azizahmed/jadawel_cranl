# Security policy

If you believe you have found a security vulnerability in Jadawel, please report it
privately by emailing a detailed description to **gotoaziz100@gmail.com**.

Please do not open a public issue, and please do not disclose the problem elsewhere
until it has been addressed.

A useful report includes:

* What the vulnerability is and which component is affected.
* Step-by-step instructions to reproduce it.
* The impact you believe it has.
* The version or commit you tested against.

You will get an acknowledgement of the report, and an update once the issue has been
assessed and a fix or mitigation is available.
