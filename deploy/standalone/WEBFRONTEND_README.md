# Jadawel's Standalone Webfrontend Image

This image runs only the Jadawel Web-frontend service and is intended for use by 
advanced users. Please instead use the `jadawel/jadawel` image if you want a simpler \
setup.

See the project [README](../../README.md) and
[configuration docs](../../docs/CONFIGURATION.md) for more details.

## About Jadawel

* A spreadsheet database hybrid combining ease of use and powerful data organization.
* Easily self-hosted with no storage restrictions.
* Alternative to Airtable.
* Open-core with all non-premium and non-enterprise features under
  the [MIT License](https://choosealicense.com/licenses/mit/) allowing commercial and
  private use.
* Headless and API first.
* Uses popular frameworks and tools like [Django](https://www.djangoproject.com/),
  [Vue.js](https://vuejs.org/) and [PostgreSQL](https://www.postgresql.org/).
